# EdulogiX Landing Page

A high-fidelity, professional landing page for **EdulogiX**, Australia's leading platform for international nurses' education and career support.

## 🚀 Quick Start

1.  **Extract** the project folder.
2.  Open `index.html` in any modern web browser.
3.  Ensure you have an active internet connection to load premium fonts (Satoshi & Inter) from Google Fonts and Fontshare.

## 📁 Project Structure

```text
edulogix/
├── index.html          # Main entry point (semantic HTML5, SEO optimized)
├── css/
│   ├── main.css        # Entry point for styles (imports all modules)
│   ├── style.css       # Core layout and structural styles
│   ├── components.css  # Reusable UI components
│   └── animations.css  # Custom CSS animations and transitions
├── js/
│   └── main.js         # Core functionality (carousel, navbar, scroll reveal, etc.)
└── assets/
    ├── images/         # Course images, testimonials, and brand assets
    ├── icons/          # Social and UI icons (SVG)
    └── video/          # Cinematic background video for the hero section
```

## ✨ Key Features

-   **Modern Aesthetics**: Premium design using a navy blue and orange palette.
    -   **Interactive Carousel**: Smooth, auto-advancing student testimonials.
    -   **Premium Review Badge**: Interactive Google Reviews widget with 169+ reviews.
    -   **Dynamic Animations**: Scroll-triggered reveals and typing effects for enhanced engagement.
    -   **Mobile First**: Fully responsive design optimized for all screen sizes.
    -   **SEO Optimized**: Includes Open Graph and Twitter Card metadata for professional social sharing.
